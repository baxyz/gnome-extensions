# gnome-extensions

Monorepo for baxyz GNOME Shell extensions.

## Extensions

| Extension | Description |
|-----------|-------------|
| [firefox-profiles](extensions/firefox-profiles) | Launch Firefox profiles from the GNOME indicator |
| [browser-hub](extensions/browser-hub) | Launch any browser profile from the GNOME indicator |

## Development

```bash
pnpm install
pnpm build     # build all extensions
pnpm test      # test all extensions
pnpm lint      # lint all extensions
```
