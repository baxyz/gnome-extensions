# Third-party assets

The badge SVGs in this directory are derived from third-party marks, recolored
to a single flat color for use as small `Gio.EmblemedIcon` badges (see
`../../src/internal/desktop-icon.ts`). Each file also carries this
information as an inline XML comment.

## flatpak-badge.svg

Extracted from the Flathub logomark (circle/square/triangle/plus), from the
official horizontal lockup at
<https://commons.wikimedia.org/wiki/File:Flathub_Logo_2023.svg>.
Apache License 2.0; Wikimedia additionally notes the mark is simple enough to
be public domain on its own.

## snap-badge.svg

The Snapcraft glyph from Ubuntu's Yaru icon theme (Canonical's own default
icon theme — the actual icon used for `snap-store`/`package-snap` on real
Ubuntu systems), from
<https://github.com/ubuntu/yaru/blob/master/icons/Yaru/scalable/apps/snapcraft-symbolic.svg>.
Licensed CC BY-SA 4.0 — this recolored version is a derivative work and is
itself distributed under CC BY-SA 4.0 (<https://creativecommons.org/licenses/by-sa/4.0/>),
consistent with the license's share-alike requirement.
